# \# Service Booking App

# 

# \## 📌 Description

# A full-stack service booking application where users can select multiple services, manage a cart, and book available time slots.

# 

# \---

# 

# \## 🚀 Features

# \- 🔍 Search services

# \- 🛒 Add multiple services to cart

# \- ❌ Remove services from cart

# \- 💰 Total price calculation

# \- 📅 Slot booking system

# \- ✅ Availability check

# 

# \---

# 

# \## 🛠 Tech Stack

# Frontend:

# \- React

# \- Bootstrap

# 

# Backend:

# \- Node.js

# \- Express

# 

# Database:

# \- MongoDB

#
